# workforce-data-analytics-capstone
End-to-end workforce data analysis using Excel, Python, SQL and Power BI
Workforce Data Analytics Capstone Project

Overview
An end-to-end data analytics project analysing workforce data to identify patterns and insights related to employee performance, education, health, department performance and compensation.

Business Objective

Identify factors associated with employee performance.
Analyse workforce and departmental trends.
Generate actionable insights to support business decision-making.

Tools & Technologies

Excel – data cleaning and exploratory analysis
Python/Pandas – data cleaning and analysis
MySQL/SQL – database creation, data management and querying
Power BI – data visualisation and dashboard development

Project Workflow

Data Collection → Data Cleaning → Exploratory Analysis → SQL Analysis → Power BI → Insights & Recommendations

Key Deliverables

Cleaned workforce datasets
SQL database and analytical queries
Exploratory data analysis
Interactive Power BI dashboard
Business insights and recommendations
